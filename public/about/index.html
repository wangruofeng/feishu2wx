用之前，
你可能想知道。

需要付费、注册或安装吗？

基础编辑、排版、预览、复制与导出都可免费使用，打开浏览器即可，无需注册或安装。项目以 MIT 许可证开源。AI 功能需要自己的模型服务，可能产生服务商费用。

不会 Markdown，也能用吗？

可以。从飞书复制正文再粘贴，工具会自动转换；加粗、斜体和链接等操作也能通过编辑工具栏完成。先用默认排版，再按需要调整设置即可。

粘贴飞书文档链接，就能导入吗？

目前不能通过文档 URL 自动读取内容。请打开飞书文档，选中并复制需要的正文，再粘贴到编辑区。转换后，建议检查标题、图片、列表与表格。

「复制」和「推送」有什么区别？

「复制」把排版结果放入剪贴板，由你粘贴到微信编辑器，不需要公众号凭证。「推送」需要公众号 AppID、AppSecret、相应接口权限与可用后端，成功后创建微信草稿，不会自动正式发布。

文章和密钥会存在哪里？

基础编辑和排版在浏览器内完成，文章、设置和历史使用浏览器本地存储，建议定期导出重要内容；清理浏览器数据可能丢失这些记录。推送时文章与公众号凭证会经后端发送给微信；使用 AI 时，请求内容会经后端发送给你配置的模型供应商。支持云配置的部署在 GitHub 登录后可加密同步模型配置。外部图片、字体仍可能发起网络请求。

为什么图片、链接还需要检查？

微信对正文格式和外链有自己的限制，图片也可能受来源站点的访问权限或防盗链影响。默认会将正文超链接转换为「文字：URL」，SVG 和 Mermaid 图形在输出时转成图片。可以在设置中关闭链接适配，但仍需检查微信侧的实际效果。请在微信编辑器与手机预览中做最后确认。

已有 Markdown，如何导出到公众号？

直接编写 Markdown，或通过「导入」打开 .md 文件，再预览并复制到微信公众号编辑器。也可以在预览区选中部分正文，只复制所选内容。HTML 导出与公众号复制使用相同的内联样式；PDF 用于保存或阅读，不能直接作为微信草稿的发布输入。

SVG、Mermaid 和 WebP 图片如何处理？

复制、HTML 导出和推送前，SVG 图片与内联 SVG（包括 Mermaid 图表）会转成 PNG。服务端向微信上传 WebP 时，静态图转 PNG，动态图转 GIF。图片最终是否正常显示，仍需在微信编辑器检查。

草稿推送失败，应该检查什么？

先检查公众号 AppID、AppSecret、接口权限与后端是否启用，再查看微信返回的错误信息。如果提示 IP 白名单问题，请按实际部署的出口 IP 配置。前端预览正常，并不代表后端发布接口已经可用。
