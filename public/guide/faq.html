feishu2wx 常见问题：公众号复制、图片和草稿箱

以下问答适用于 feishu2wx 网页编辑器。基础排版可在浏览器执行；直接创建微信草稿和 AI 改稿依赖对应后端及外部服务。

需要登录才能排版吗？

基础排版、预览和复制不要求 GitHub 登录。支持云端配置的部署可通过 GitHub 登录同步 AI 配置；直接推送草稿需要公众号凭证。

可以粘贴飞书文档链接自动导入吗？

当前输入方式是复制飞书文档正文并粘贴富文本，或输入、导入 Markdown；没有通过飞书文档 URL 自动读取文档的功能。

复制公众号和推送草稿箱有什么区别？

复制将排版后的 HTML 放入剪贴板，需要手动粘贴到微信公众号编辑器。推送通过后端调用微信 API 创建草稿，需要 AppID、AppSecret 及公众号接口权限；不会自动正式发布。

公众号中的超链接为什么变成文字？

默认开启公众号链接自动适配，将链接转换为“链接文字：URL”，避免公众号正文超链接被吞。可以在设置中关闭适配，但仍需检查微信侧实际效果。

SVG、Mermaid 和 WebP 图片如何处理？

复制、HTML 导出和推送前，SVG 图片与内联 SVG（包括 Mermaid 图表）会转为 PNG。服务端向微信上传 WebP 时，静态图转 PNG，动态图转 GIF。图片是否最终正常显示仍需在微信编辑器检查。

草稿推送失败应该检查什么？

检查 AppID、AppSecret、公众号接口权限、后端是否启用以及微信返回的错误信息。若微信提示 IP 白名单问题，按实际部署的出口 IP 配置；不要仅凭前端预览正常判断发布 API 可用。

AI 改稿是免费的吗？

基础排版与 AI 调用是不同流程。AI 需要配置模型服务，是否收费、额度与可用性取决于该供应商；应用不会提供默认的免费模型额度。
