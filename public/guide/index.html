feishu2wx 使用指南：飞书与 Markdown 转微信公众号

feishu2wx 是 MIT 开源的微信公众号排版工具。它将粘贴的飞书富文本转换为 Markdown，再将预览转换为带内联样式的公众号 HTML。适合已有飞书文档或 Markdown 文章、需要调整公众号排版的作者。

功能与使用边界

内容输入
飞书富文本粘贴、Markdown 编写或 .md 文件导入；不通过飞书文档 URL 自动读取文档。
排版与输出
支持主题、代码高亮、表格、脚注、任务列表与 Mermaid；可复制到公众号编辑器，导出 Markdown、HTML、PDF。
价格与许可
项目以 MIT 许可证开源，基础排版可免费使用。AI 功能需要配置模型服务，费用与可用性由对应服务商决定。
草稿发布
推送草稿需要配置公众号 AppID、AppSecret，并使用支持发布 API 的后端部署。推送成功表示创建草稿，文章正式发布仍需在微信后台完成。

如何把飞书文档排版到公众号？

  1. 在飞书文档中复制需要的正文，在 feishu2wx 编辑区粘贴；检查标题、列表、图片和表格的转换结果。
  2. 打开设置选择主题与字体，调整标题、引用块和代码块样式，在右侧预览。
  3. 使用复制功能，将结果粘贴到微信公众号编辑器。预览区选中部分正文时，也可仅复制所选部分。
  4. 在微信编辑器检查图片、列表、代码块和链接，再保存草稿或发布。

如何将 Markdown 转为公众号排版？

直接输入 Markdown 或导入 .md 文件，查看实时预览后复制到公众号编辑器。HTML 导出使用与公众号复制相同的内联样式管线；PDF 适合保存或阅读，不是微信草稿发布的输入格式。

数据会发送到哪里？

基础编辑与排版在浏览器中执行，设置和历史文档保存在 localStorage。推送草稿时，公众号凭证与文章通过后端发送给微信 API；使用 AI 时，请求内容通过后端发送给配置的模型供应商。支持云端配置的 Cloudflare 部署在 GitHub 登录后可加密同步模型配置。第三方图片和字体仍可能产生网络请求。
