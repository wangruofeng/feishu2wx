## 输入内容

### 粘贴飞书文档

在飞书文档中复制内容（Cmd/Ctrl+C），直接粘贴到左侧编辑器，自动转换为 Markdown：

- 飞书高亮标记转换为 `==高亮==` 语法
- 代码块、表格、任务列表等结构完整保留
- 粘贴检测逻辑支持飞书/Lark 标记、HTML 表格、渲染后 Markdown 等多种来源
- 如果来源 HTML 中包含 `data-lark`、`larksuite`、`feishu.cn` 等关键词导致误判，可在设置面板关闭「智能 HTML 转 Markdown」

### 智能 Markdown 识别

从渲染后的 Markdown 页面（如博客、文档站）复制内容时，即使剪贴板 `text/plain` 已丢失 Markdown 语法，编辑器也会按 HTML 结构还原标题、列表和代码块，而不是退化成普通文本。

### 导入与历史

- **导入 `.md` 文件**：编辑器底部「📂 导入」按钮，或直接把文件拖进编辑区
- **图片附件**：图片（含 SVG）拖拽 / 粘贴到编辑区直接插入为 data URI 图片，单图限 2MB
- **历史文档**：导入、清空、加载示例等替换操作前旧内容自动存档（上限 20 条），点击底部「历史文档」按钮找回；内容相同的记录不会重复保存

## 编辑与预览

### 工具栏

编辑器底栏的「格式」按钮向上展开菜单，分为标题、文字格式和插入内容三组，包含 H1 / H2 / H3、粗体、斜体、行内代码、列表、引用、链接和图片。选择操作后自动收起并回到编辑器，支持方向键移动和 Esc 关闭。底部同时提供导入、加载示例、清空、字数统计、文章大纲、历史文档。

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| Cmd/Ctrl + B | 粗体 |
| Cmd/Ctrl + I | 斜体 |
| Cmd/Ctrl + U | 下划线 |
| Cmd/Ctrl + K | 插入链接 |
| Cmd/Ctrl + F | 打开 Markdown 原文查找替换 |
| Cmd/Ctrl + Z / Shift + Z | 撤销 / 重做（50 步历史） |

完整快捷键列表可点击右下角浮动按钮「?」打开快捷键面板查看。

### 查找与替换

按 Cmd/Ctrl + F 打开编辑区顶部的双行查找替换栏。支持普通文本、区分大小写和正则表达式；Enter / Shift + Enter 跳到下一个 / 上一个匹配。编辑区会高亮全部匹配并强调当前项，可替换当前项或一次替换整篇 Markdown 原文。正则模式的替换内容支持 `$1` 等捕获组引用；非法正则只显示错误，不会修改原文。

### 文章大纲

编辑器底部「大纲」按钮解析文章中的 H1-H3 标题（自动跳过 frontmatter 与代码块），点击大纲项滚动定位到对应位置。

### 预览模式

- **专注工作区**：顶栏的两枚面板图标按钮（悬停提示「仅编辑」/「仅预览」）互斥切换；再次点击当前选项可回到双栏工作区
- **图片查看器**：点击预览区图片放大查看，键盘左右键切换

### 源码配色

编辑器源码与预览代码块共享同一套语法高亮配色，在设置面板「编辑体验 → 源码配色」中切换 GitHub / Dracula / Monokai / 无 四种方案；切换会同时影响编辑器 Markdown 源码、预览代码块以及复制 / 导出 / 推送内容中的代码配色，「无」表示不做语法高亮。

## 排版设置

点击右上角设置（齿轮）按钮打开排版设置面板。所有文章主题都统一在此配置。桌面端设置面板从右侧展开并为编辑区预留空间，面板顶部的分类标签栏与顶栏等高对齐，内容区不再重复显示分类大标题；手机端保持覆盖式抽屉和顶部横向分类标签。分类内容较长时可在设置内容区独立滚动：

| 分组 | 配置项 |
|------|--------|
| 主题外观 | 预设主题色、自定义主题色、字体，以及主题的保存、应用、导入、导出和删除 |
| 文章排版 | H1/H2 样式、正文对齐、分割线、荧光笔颜色、元数据和文章首尾片段 |
| 内容样式 | 引用块、图片、表格和代码块样式 |
| 编辑体验 | 智能粘贴、Markdown 源码配色、AI 面板显示方式、聊天 Token 统计和界面明暗 |
| 发布数据 | 微信公众号链接适配、草稿箱推送配置和完整配置导入导出 |

### 主题

内置 4 种预设主题色 + 自定义主题：

- **经典**（默认）- 黑白风格，适合正式文章
- **橙色** - 活力风格，适合活动、促销类文章
- **蓝色** - 清新风格，适合商务、专业类文章
- **青绿** - 自然风格，适合科技类文章
- **自定义** - 挑选任意主色，自动生成标题、引用块、链接等整套配色；清空主色可恢复预设

在设置面板「主题外观」中，先配置字体和自定义主题色，再从下方“预设主题色”切换经典、橙色、蓝色或青绿。

界面本身支持浅色 / 深色 / 跟随系统三种模式，与文章主题独立。

## 保存主题

如果需要重复使用一整套文章排版，可以在设置面板「主题管理」中输入名称并点击「保存当前配置」。浏览器可保存多份主题；刷新页面后仍会保留。

- 在设置面板「主题管理」列表点击主题名称即可切换为已保存主题
- 当当前排版与某个保存主题的完整配置一致时，该主题会显示勾选和“当前”；继续修改任一排版项后标识自动消失
- 主题保存的是创建时的配置快照；应用后继续调整不会自动覆盖原主题
- 使用相同名称再次保存时，可确认覆盖原主题
- 每份主题都能单独导出为 `feishu2wx-theme-<主题名>.json`，导入后只加入主题列表，不会自动改变当前排版
- 删除和覆盖均会先确认，取消后不会修改已保存数据

主题包含颜色及自定义主色、字体、标题、正文、代码块、图片、表格、引用块和荧光笔等文章排版选项。主题不包含正文、历史文档、首尾模板、链接适配、深浅模式、编辑器与 AI 偏好，也不包含任何凭证。

「主题外观」中的主题 JSON 只保存文章排版，适合在多套样式之间日常切换；「发布数据」中的完整配置 JSON 用于备份和恢复更完整的用户级设置，两种文件格式不能混用。主题保存在当前浏览器的 localStorage 中，不会自动跨设备同步。

### 字体

17 种免费无版权字体：系统默认、微软雅黑、宋体、黑体、苹方、Arial、Helvetica、Times New Roman、Georgia、Verdana、Courier New，以及 Google Fonts 的 Roboto、Open Sans、Lato、Montserrat、Raleway、Poppins。

> Google Fonts 字体需要联网加载，网络受限时可使用系统字体。

## Markdown 渲染特性

- **Task List** - `- [x]` / `- [ ]` 渲染为 ☑ / ☐ 复选框
- **脚注** - `[^1]` + `[^1]: 定义` 渲染为上标引用与脚注区块
- **frontmatter** - YAML front matter 在预览中显示为元数据卡片（数组字段渲染为标签徽章），复制 / 推送时自动剥离
- **高亮** - `==高亮==` 语法，5 种荧光笔颜色可在设置面板配置
- **Mermaid 图表** - ` ```mermaid ` 代码块渲染为图表，复制 / 导出时自动栅格化为 PNG
- **SVG** - SVG 语法 / data URI / 粘贴的内联 SVG 全链路保留为图形
- **表格** - 支持表格与移动端横向滚动，可选表格阴影
- **代码块** - 语法高亮配色跟随「源码配色」（未选择时默认 Atom One Dark）+ 语言标签；极简 / 现代两种风格
- **行内代码** - 渲染为加粗样式，便于在公众号中区分
- **标题间距** - H1: 24px、H2: 18px、正文: 16px；H1 / H2 有更大的上边距（首个 H1 除外）

## 复制到公众号

1. 点击顶部「复制」按钮
2. 打开微信公众号编辑器，Cmd/Ctrl + V 粘贴

行为细节：

- **选中复制**：预览区选中了部分内容时仅复制选中部分，未选中则复制全文
- **样式内联**：主题、字体、代码高亮等样式全部转为内联样式，公众号编辑器可完整保留
- **链接自动适配**（默认开启）：公众号正文超链接经常被吞，开启时链接转为「链接文字： URL」纯文本（链接文字与 URL 相同时只显示一次）；关闭时保留超链接
- **标签白名单**：微信导出使用保守标签子集（`p` / `span` / `strong` / `em` / `ul` / `ol` / `li` / `section` / `blockquote` / `h1-h6` / `table` / `img` 等），`figure` / `figcaption` 等不稳定标签自动降级或过滤
- 复制失败时自动降级到兼容方案；仍失败可手动选中预览区内容复制

## 导出文件

顶部「导出」下拉菜单支持三种格式，文件名自动取文章标题（frontmatter `title` 或首个 H1）：

- **Markdown** - 直接下载当前 Markdown 源码（含首尾模板拼接）
- **HTML** - 复制 / 推送同款排版管线产出的内联样式 HTML，浏览器双击即可预览
- **PDF** - 载入排版后的 HTML 调用浏览器打印对话框，选择「另存为 PDF」

## 推送到草稿箱

1. 设置面板「公众号」组点击「去配置」，输入 AppID 和 AppSecret（[微信公众平台](https://mp.weixin.qq.com) 获取）
2. 点击顶部「推送」按钮，确认标题、作者、封面后推送

行为细节：

- **标题自动填充**：优先读 frontmatter `title`，其次正文首个 H1，均为空时显示「未命名文章」
- **封面自动读取**：frontmatter `cover` 字段；未指定时取正文首图
- 凭证仅保存在浏览器 localStorage，推送时随请求发送给后端调用微信 API，服务端不存储
- 推送需要后端：本地用 `npm run dev` 启动，或使用 Cloudflare 部署版；纯前端启动（`npm start`）推送不可用

## AI 聊天编辑

点击右下角浮动按钮「AI」打开 AI 面板（抽屉浮层 / 右侧侧栏两种显示方式，设置面板可切换）：

- 发送自然语言指令修改当前文章，如「把这段总结成三个要点」
- 支持图片 / 文本附件，流式输出，思考过程可展开查看
- 修改建议先以 diff 形式「查看变更」，确认后「应用修改」回写编辑器
- 聊天历史本地保存，AI 对话不会自动改动文章，只有点「应用修改」才会生效

**模型配置**（面板内「模型设置」）：

- 自定义供应商，兼容 Chat Completions / Anthropic / Responses / Google Generative AI 四种 API 格式
- 未登录时为本地 BYOK 模式，API Key 仅保存在浏览器
- Cloudflare 部署版支持 GitHub 登录，配置 AES-GCM 加密同步到云端，浏览器端不暴露 API Key，跨设备可用
- 「获取模型列表」会从供应商目录读取可用模型，自动去重并追加，保留手动添加的模型；失败可重试。不支持目录接口的供应商可继续手动填写模型 ID。
- Google Generative AI 使用原生 Gemini 协议，Base URL 可填 `https://generativelanguage.googleapis.com/v1beta`，支持文字、图片和文本附件。
- 模型设置底部「配置迁移」可导出 `feishu2wx-model-settings.json`，或导入本项目 / A2Make 的 v1 聊天模型配置。导入可选「新增供应商」或「完全覆盖」，后者确认后替换全部模型配置。
- 模型配置文件与下方的排版配置文件分开。模型配置导出包含浏览器当前已有的 API Key；云端隐藏的已保存密钥不会导出，其他设备导入后需重新填写。最多支持 20 个供应商，每个供应商 1000 个模型，文件上限 1 MiB。
- 聊天 Token 统计默认关闭，可在「设置 → 编辑体验 → 显示聊天 Token 统计」手动开启，选择会保存在当前浏览器并随配置备份导入导出。开启后，每条助手回复底部显示 Token 用量，点击可查看输入、输出、缓存与推理等明细。用量来自上游返回；总计缺失时只有输入和输出均已知才计算，缺失项标为「未返回」，不会估算。用量随本地聊天历史保留。

## 配置迁移

设置面板「发布数据 → 完整配置」支持排版设置的备份与恢复：

- **导出 JSON** - 下载 `feishu2wx-config.json`，包含主题、字体、排版选项、首尾模板等全部排版设置
- **导入 JSON** - 选择导出的文件，逐项校验后恢复设置
- 导出格式与 CLI 用户级配置 `~/.feishu2wx/config.json` 同构，可互相导入
- 不包含文章、历史记录，也不含任何 API Key、AppSecret 等凭证

## 多用户使用

本工具支持多用户共用同一个在线部署：

- 每个用户在各自浏览器中配置自己的公众号凭证，数据完全隔离
- 凭证仅保存在浏览器本地，不经过服务器存储，互不干扰
- 无需各自部署，开箱即用

## 常见问题

### 复制公众号失败？

确保浏览器允许剪贴板权限（部分浏览器需要 HTTPS 环境）。自动复制失败时可手动选中预览区内容，Cmd/Ctrl + C 复制。

### 飞书粘贴后格式不正确？

确保从飞书文档完整复制。部分复杂格式需手动调整；也可先粘贴到纯文本编辑器再复制进来。

### 图片不显示？

图片需使用 `![描述](URL)` 语法且 URL 公开可访问，建议使用图床托管。本地图片可拖拽 / 粘贴到编辑区直接插入。

### 字体不生效？

Google Fonts 字体需联网加载，加载完成前会回退系统字体；网络受限时直接选择系统字体。

### 主题样式在公众号里丢失？

务必使用「复制」按钮（样式已内联化），手动复制无法保留样式。粘贴后可在公众号编辑器检查是否保留了富文本格式。

### 推送失败？

- 推送需要后端服务：本地开发用 `npm run dev`，在线版需 Cloudflare 部署
- 检查 AppID / AppSecret 是否正确
- 在微信公众平台「设置与开发 → 基本配置」中将部署服务器 IP 加入白名单

AI 助手顶部的模型切换列表最大高度为 440px，可展示更多模型；较矮屏幕会自动收缩，超出部分可滚动查看。

模型设置的供应商配置页支持「清空列表」，仅清空当前供应商的模型，保留连接配置与其他供应商；清空时会取消正在获取的模型目录，避免旧结果重新填入。工具栏同时显示目录总数（获取后）和已添加数量。

供应商配置页通过名称旁的 Switch 开关启用或禁用供应商，状态徽章同步更新。禁用会保留供应商连接配置和模型列表。

### AI 助手多会话

AI 助手顶部的会话工具栏支持切换、新建、重命名和删除会话。新会话首次发送时会自动用首条指令命名，也可以通过铅笔按钮修改名称。

每个会话独立保存消息、模型选择、文字草稿和输入历史；新会话继承当前模型作为初始选择，之后可分别切换。每条 AI 回复上方显示本轮实际使用的供应商和模型，后续改名或切换不会改写历史标识。供应商被禁用、模型被移除时会提示重新选择。

生成期间可以切换到其他会话继续聊天，回复仍写回原会话。「停止生成」和「清空对话」只影响当前会话；删除会话需确认，正在生成的请求也会随之取消。

会话记录保存在当前浏览器，刷新可恢复文字草稿、模型选择和每会话最近 20 条消息，不同步到云端。旧单会话记录会自动迁入「历史会话」，没有来源信息的旧回复不会补写当前模型。图片和附件正文只在当前页面内存保留，刷新后需重新添加。

主编辑器文章仍为共享文档，各会话发送时读取当前正文；应用修改稿时沿用文章变更冲突确认。

- 三列时隐藏 GitHub、关于、加载示例、清空和行数字数统计；设置分类按面板宽度自动换行，侧栏不超过 320px 时改为下拉选择。
- 删除、清空与覆盖统一使用自定义确认弹窗；模型列表的排序和删除按钮在悬停或键盘聚焦时显示，触屏保持可见。


### 链接转文末注脚

打开「设置 → 发布数据 → 公众号」，开启「链接转文末注脚」。正文保留链接文字和上标编号，完整网址集中到文末，重复网址复用编号；已有 Markdown 注脚可保留并续号。此选项优先于「微信公众号链接自动适配」，默认关闭，刷新页面后保留。

预览、复制（包括选中内容）、HTML/PDF 导出和草稿推送使用同一转换逻辑，源 Markdown 和 Markdown 导出不变。完整配置 JSON 导入导出包含 `wechatLinkFootnotes`，与 CLI 的同名配置字段一致。
