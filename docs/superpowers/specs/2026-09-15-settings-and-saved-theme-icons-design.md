# 设置分类与「我的主题」图标改版设计

## 背景与目标

设置弹框左侧分类当前使用 `◐`、`¶`、`▦`、`⌨`、`↑` 等文字字形，不同平台的字形、视觉重量和基线不一致；主页「我的主题」右侧使用 `⌄` 字符，也与项目已有的 Lucide 风格齿轮图标不统一。

本次只改进这两处图标的视觉表达，不调整菜单结构、文案、状态、数据或键盘交互。

## 视觉方向

采用已确认的 A「精准线性」方向：

- 所有分类图标使用本地 React SVG，尺寸统一为 `17px`，描边统一为 `1.7px`。
- 图标使用 `currentColor`，默认继承分类文字的次级色，选中后继承品牌色。
- 不增加图标底板、渐变或额外阴影，延续当前设置面板的紧凑、克制风格。
- 线端和转角使用圆角，保持与共享 `GearIcon` 的 Lucide 线性语言一致。

## 图标映射

| 分类 | 图标语义 |
| --- | --- |
| 主题与外观 | 太阳：界面主题、颜色与明暗 |
| 文章排版 | 字体：字体、标题和正文排版 |
| 内容样式 | 分区布局：图片、表格、引用等内容块 |
| 编辑体验 | 键盘：编辑器输入与交互偏好 |
| 发布与数据 | 向上上传：发布、配置迁移和数据操作 |

「我的主题」右侧使用 14px 线性折角箭头。关闭时向右，打开时通过 CSS 旋转为向下，动画时长约 150ms；箭头仅表达展开状态，不成为独立交互目标。

## 组件边界

- 新增共享的设置分类图标组件，接收分类 ID 并返回对应 SVG，避免在配置数组内堆叠 JSX。
- 新增或复用轻量 Chevron SVG 作为 `SavedThemeMenu` 的状态指示图标。
- `SettingsPanel` 的分类数据移除字符图标字段，由分类 ID 决定图标。
- 所有装饰图标使用 `aria-hidden="true"`；按钮原有文字继续提供可访问名称。

## 响应式与交互

- 桌面端保持左侧纵向分类导航的现有宽度、间距和选中指示条。
- 移动端保持顶部横向滚动分类导航，图标与文字不换行。
- 「我的主题」保持现有点击、外部点击关闭、Esc 关闭和焦点返回行为。
- 展开状态只驱动箭头方向，不引入新的状态源。

## 验收标准

1. 五个设置分类均显示语义明确、尺寸一致的线性 SVG，不再依赖系统字符字形。
2. 分类选中、悬停、聚焦状态在明暗主题下均清晰可见。
3. 「我的主题」关闭时箭头向右，展开时平滑转向下方。
4. 桌面和不宽于 768px 的移动布局均不发生溢出、错位或文字换行回归。
5. 现有分类键盘导航和主题菜单关闭行为保持不变。
6. 组件测试覆盖分类图标、装饰性可访问属性和箭头展开状态。

## 非目标

- 不更换全站其他工具栏图标。
- 不引入新的图标库或运行时依赖。
- 不改变设置分类的信息架构、菜单内容或主题保存逻辑。
