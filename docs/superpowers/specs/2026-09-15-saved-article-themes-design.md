# 文章排版主题保存与切换设计

## 背景与目标

feishu2wx 目前提供五种颜色主题和一组分散在设置面板中的文章排版选项，但用户无法把一套完整排版组合保存下来重复使用。

本功能允许用户将当前文章排版配置保存为具名主题，在同一浏览器中保存多份，并支持主题切换、单份导出和导入。

## 范围

主题只包含会影响文章预览和微信公众号输出的排版配置：

- 颜色主题与自定义主色
- 字体
- 代码块样式
- 图片边框样式与圆角
- H1 下划线、反色和左对齐
- H2 反色、左对齐和下划线
- 分割线显示
- Frontmatter 元数据卡片显示
- 表格阴影
- 引用块背景、边框色和间距
- 正文对齐
- 荧光笔颜色

以下内容不属于主题：

- Markdown 正文和历史文档
- 飞书 HTML 粘贴转换偏好
- 文章首尾模板及显示开关
- 微信链接自动适配
- 应用深浅模式、编辑器语法高亮和 AI 面板模式
- 微信凭证、AI API Key、聊天记录及其他账号数据

## 交互设计

### 快速切换

保留顶栏现有的经典、橙色、蓝色、青绿和自定快捷按钮，并在其后增加“我的主题”入口。入口打开已保存主题列表，用户点击一项即可立即应用全部排版配置。

当没有保存主题时，列表显示空状态并引导用户前往设置保存。移动端沿用现有顶栏主题控件的隐藏策略，主题管理仍可从设置面板访问。

### 主题管理

设置面板新增“主题管理”分组，包含：

- 主题名称输入框与“保存当前配置”按钮
- 已保存主题列表
- 每份主题的“应用”“导出”“删除”操作
- 导入主题 JSON 的按钮和隐藏文件输入框

名称去除首尾空格后不能为空。同名保存时通过确认提示决定是否覆盖；取消后不写入。删除主题也需要确认。

应用主题后，用户继续调整设置只改变当前工作配置，不自动改写主题快照。需要再次以同名保存并确认覆盖，才更新已保存主题。

导入成功后只加入主题列表，不自动应用，避免意外覆盖当前工作配置。同名导入时同样要求确认覆盖。

## 数据模型与持久化

新增 `SavedArticleTheme`：

```ts
interface SavedArticleTheme {
  id: string;
  name: string;
  createdAt: number;
  updatedAt: number;
  settings: ArticleThemeSettings;
}
```

`ArticleThemeSettings` 只声明范围章节列出的字段，不复用包含应用偏好、模板和发布行为的完整 `SettingsBackup`。

主题集合以 JSON 数组保存在 `localStorage` 的 `feishu2wx_savedThemes` 键中。主题 ID 在创建时生成，名称用于用户识别和同名检测。列表按最近更新时间倒序展示。

读取时对集合结构逐项校验；单个损坏条目被忽略，其余合法主题仍可使用。写入失败时保留内存中的原状态，并向用户显示失败提示。

## 导入与导出格式

每次只导出一份主题，文件结构如下：

```json
{
  "version": 1,
  "type": "feishu2wx-theme",
  "name": "我的技术文章",
  "settings": {
    "theme": "blue",
    "customThemeColor": "",
    "font": "default",
    "codeBlockStyle": "modern"
  }
}
```

实际 `settings` 必须包含完整主题字段。导出文件名经过安全化处理，格式为 `feishu2wx-theme-<主题名>.json`。

导入按以下顺序校验：

1. JSON 可解析且根节点为对象。
2. `version` 为 `1`，`type` 为 `feishu2wx-theme`。
3. 名称为去除首尾空格后的非空字符串。
4. `settings` 仅包含主题白名单字段，并逐字段检查类型和枚举值。
5. 所有必填主题字段齐全。

校验失败时不修改主题集合，并显示明确错误。主题文件不兼容现有“配置迁移”文件；两者入口和用途保持独立，避免用户误把全局配置当成排版主题。

## 代码边界

- `src/utils/savedThemes.ts`：类型、字段校验、localStorage 读写、导入解析和导出序列化。
- `src/components/SavedThemeMenu.tsx`：顶栏快速切换入口及主题列表。
- `src/components/SettingsPanel.tsx`：主题命名、保存、导入、应用、导出和删除管理界面。
- `src/App.tsx`：从当前 React 状态生成主题快照，并以单个应用函数把主题设置写回全部相关状态。

主题字段清单和校验规则集中在工具模块中，保存、导入与应用共享同一类型，避免三个入口产生字段漂移。

## 错误处理

- localStorage 不可用、容量不足或写入异常：操作失败，保留旧集合并显示错误。
- 导入文件格式错误、版本不支持或字段非法：拒绝导入，不产生部分写入。
- 同名保存或导入：确认后覆盖，并保留原主题 ID 与创建时间，刷新更新时间。
- 当前列表中不存在目标主题：不应用并刷新列表状态。

所有状态反馈使用设置面板内的可访问状态文本；浏览器确认框只用于覆盖和删除这类破坏性操作。

## 测试与验收

工具模块单元测试覆盖：

- 多主题保存、读取、排序、覆盖和删除
- localStorage 异常与损坏条目恢复
- 导入导出往返一致性
- 非法 JSON、错误版本/类型、空名称、缺失字段、非法枚举和额外字段
- 导出内容不包含模板、应用偏好、正文或凭证

应用层回归测试覆盖：

- 保存当前配置后列表出现主题
- 应用主题会一次性更新所有文章排版字段
- 应用后再修改配置不会自动改写快照
- 导入只加入列表，不自动应用
- 同名操作和删除遵守确认结果

完成标准：用户可保存多份文章排版主题，从顶栏或设置面板切换，逐份导出并重新导入；刷新页面后主题仍存在，且任何主题文件都不包含范围外数据。
