# 产品介绍页字号与排版

适用范围：`public/about/`，独立于编辑器界面和公众号文章输出。

## 字号层级

| 用途 | 桌面 | 手机（≤600px） | 字重 |
| --- | --- | --- | --- |
| 首屏主标题 | 64px | 36–40px | 700 |
| 模块标题 | 32px | 28px | 600 |
| 功能与步骤标题 | 20px | 20px | 600 |
| 正文、按钮、FAQ | 16px | 16px | 400–500 |
| 说明、标签、页脚 | 12–13px | 12–13px | 400 |

字号通过 `about.css` 中的 `--type-*` 维护。示例文章主标题为 24px，源码示例为 14px，分别对应文章和代码场景。

## 排版原则

- 参考 [Mole 官网](https://mole.fit/zh/) 的层级跨度与正文收敛规律。2026-10-18 在 1280px 视口实测：Mole 品牌标题为 96px / 500，模块标题为 32px / 500；本页根据长中文标语采用 64px，不将此前估算表当作官方设计规范。
- 使用本机中文无衬线字体；靠字号、字重和留白区分层级，代码使用等宽字体。无需新增字体请求。
- 桌面内容最大宽度 1040px，正文行高 1.8；章节间距为桌面 104px、平板 80px、手机 64px。
- 减少标题上方重复的章节标签；保留有顺序含义的三步上手编号。
- 850px 及以下，排版示意和步骤改为纵向排列，避免为双栏缩小文字。600px 及以下，功能与 FAQ 改为单栏；正文仍保持 16px。
- 配色切换沿用原生 radio，FAQ 沿用原生 details 及现有动画增强；保留键盘焦点和系统减少动态效果支持。

## 分割线使用

页面章节、步骤、功能项、首尾区域通过留白分组，不使用重复横线。仅保留排版示意窗口的外框、工具栏与双栏边界，以及相邻 FAQ 项之间的细线。示例文章中的标题下划线与引用边框用于展示文章样式，按钮与选中状态的边框仍保留。

## 统一帮助入口

网站仅维护 `/about/` 一个介绍与帮助页。原使用指南的操作说明、图片兼容和推送排错已并入正文或 FAQ；编辑器、加载兜底、sitemap 与 llms.txt 均指向关于页。`public/_redirects` 保留旧 `/guide/`、`/guide/index.html`、`/guide/faq` 等地址的 301 跳转，分别落到 `#start` 和 `#faq`。仓库内的 `docs/usage.md` 继续作为详细参考文档。FAQ 结构化数据需与页面可见问答保持一致。
